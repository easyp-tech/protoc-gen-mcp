# @easyp-tech/protoc-gen-mcp-runtime

Runtime for TypeScript MCP servers generated by
[protoc-gen-mcp](https://github.com/easyp-tech/protoc-gen-mcp) with
`lang=typescript`. Generated `*_mcp.ts` files import it for the tool, prompt
and resource registries, dispatch, URI templates, content encoding, and the
stateless Streamable HTTP handler with its OAuth scope gate and RS256 JWKS
verifier (on `jose`). `@modelcontextprotocol/sdk`, `@bufbuild/protobuf` and
`ajv` are peer dependencies, so the server and the runtime share one SDK.

The package is not published to npm yet. Install the tarball attached to the
GitHub release of the plugin version you generate with:

```sh
npm install https://github.com/easyp-tech/protoc-gen-mcp/releases/download/v1.0.0/easyp-tech-protoc-gen-mcp-runtime-1.0.0.tgz
```

Inside this repository it is consumed through a `file:` dependency
(`"@easyp-tech/protoc-gen-mcp-runtime": "file:../../runtime/typescript"` with
`install-links=true`), as `examples/8_typescript_standalone` and
`internal/codegen/testdata/node` do. Build it before installing those
consumers, and rerun `npm ci` in them after changing it:

```sh
npm ci
npm run build
npm test
```

The runtime and the generator are versioned together: generated code checks
`GENCODE_VERSION` on load and fails with a clear message when they drift.
