# protoc-gen-mcp-runtime

Runtime for Python MCP servers generated by
[protoc-gen-mcp](https://github.com/easyp-tech/protoc-gen-mcp) with
`lang=python`. Generated `*_mcp.py` modules import it to register their tools,
prompts and resources on a low-level `mcp.server.lowlevel.Server`.

```sh
pip install protoc-gen-mcp-runtime
```

The runtime and the generator are versioned together: generated code checks
`GENCODE_VERSION` on import and fails with a clear message when they drift.
